01 · Link
Connect to controller
Same UART wire protocol as the Penov/Penoff BafangConfigTool (1200 baud), rebuilt for Web Serial. Works in Chrome, Edge, or Opera on desktop. Plug in your USB–UART cable, then hit Connect and pick the port.
Web Serial isn't available in this browser. Open this file in a recent desktop Chrome, Edge, or Opera to connect to real hardware. You can still browse the tabs and load/inspect .el profiles below.
Session

Connect pings the controller for its General block (manufacturer, model, firmware, nominal voltage, max current) — same handshake the original tool performs.
Read all chains Basic → Pedal Assist → Throttle reads, exactly like the original "READ FLASH" button. Do this twice on first connect, per the community's own advice — the first read is sometimes a stale/garbage frame.

03 · Pedal Assist tab
Cadence response tuning
How the motor reacts to pedaling: sensor type, start behaviour, and how quickly it lets go when you stop — the parameter that protects your drivetrain during shifts.
What each setting does — tap to expand
SettingIncreasing it →
Start CurrentStronger kick from a standstill — the main lever for a punchier launch. Also stresses the controller/gear more at 0 cadence.
Slow-start ModeFaster power ramp-up when you start pedaling — snappier, but rougher on the drivetrain.
Startup DegreeMore pedal-signal pulses required before assist kicks in — higher = slower to respond, lower = snappier engagement.
Time of StopLonger delay before the motor lets go once you stop pedaling — worse for shift protection, but smoother PAS on rough trail.
Current DecaySlower/gentler fall-off in power as your effort drops.
Keep CurrentPower stays stronger as cadence rises — less "fade" mid-pedal-stroke, more sustained pull.
Community consensus: negligible effect on BBS02 — safe to leave undetermined.
Lower = motor lets go faster when you stop pedaling. Protects the chain during shifts. BBS02B may floor around 20.

SettingIncreasing it →

Mode: Current vs SpeedCurrent mode = smoother, controller manages power directly. Speed mode = punchier but jerkier, throttle position ≈ target speed.
