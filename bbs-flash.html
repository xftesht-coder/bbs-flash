Reality Check — drivetrain ceiling
Top speed is not set by watts, it is set by how fast the crank can spin and what gear that crank drives. Below the motor's RPM ceiling nothing else matters — more current only makes heat.
Overheating is a gear choice, not a wattage number. Set this to the gear you honestly stay in on a long forest climb.

Crank RPM ceiling is a family estimate — BBS01 ≈78–100, BBS02 ≈120, BBSHD ≈130–150 — not a value the controller reports. Measure yours on a stand (rear wheel off the ground, full throttle in the highest gear, read cadence off the 850C) and put the real number in here. Until then every speed on this page carries that uncertainty.

06 · Wire log
Raw frame trace
Every byte sent/received, for debugging a stubborn connection or verifying nothing unexpected is being written.

Leave strict mode off for the first “Read all”: the log will print which checksum span your controller uses. Once you have seen it match cleanly, turn it on and leave it on — that is what stops a corrupted read from quietly becoming your next write.
