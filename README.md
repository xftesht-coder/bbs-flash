# BBS Flash v3.0

Веб-конфигуратор моторов Bafang BBS01/BBS02/BBSHD через Web Serial API.

🔗 **Открыть приложение:** https://xftesht-coder.github.io/bbs-flash/

## Файлы

- `bbs-flash.html` — само приложение
- `bafang_intelligence.md` — исследование: физика, пресеты, протокол, локализация
- `bafang_intelligence_reader.html` — то же исследование в читаемом виде, [открыть](https://xftesht-coder.github.io/bbs-flash/bafang_intelligence_reader.html)
- `ROADMAP.md` — план разработки, скоуп v3.0
- `CLAUDE_CODE_PROMPTS.md` — промты для дальнейшей разработки в Claude Code

## Важно

Подключение к мотору (кнопка Connect) требует Chrome/Edge/Opera на desktop
и работает по HTTPS — GitHub Pages это обеспечивает.

⚠️ Протокол Bafang reverse-engineered. Изменение параметров тока и
напряжения может повредить оборудование. Используйте на свой страх и риск.
