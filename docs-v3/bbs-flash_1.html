01 · Link
Connect to controller
Same UART wire protocol as the Penov/Penoff BafangConfigTool (1200 baud), rebuilt for Web Serial. Works in Chrome, Edge, or Opera on desktop. Plug in your USB–UART cable, then hit Connect and pick the port.
Web Serial isn't available in this browser. Open this file in a recent desktop Chrome, Edge, or Opera to connect to real hardware. You can still browse the tabs and load/inspect .el profiles below.
Session

Connect pings the controller for its General block (manufacturer, model, firmware, nominal voltage, max current) — same handshake the original tool performs.
Read all chains Basic → Pedal Assist → Throttle reads, exactly like the original "READ FLASH" button. Do this twice on first connect, per the community's own advice — the first read is sometimes a stale/garbage frame.
