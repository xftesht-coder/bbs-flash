## 0. САМОЕ ПЕРВОЕ: создать CLAUDE.md

В Claude Code файл `CLAUDE.md` в корне проекта подхватывается **автоматически** при каждом запуске. Правила пишутся один раз.

Запусти `claude` в папке проекта и вбей:

```
Создай в корне файл CLAUDE.md со следующим содержимым (скопируй как есть):

# BBS Flash v3.0 — правила проекта

## Что это
Веб-конфигуратор моторов Bafang BBS01/BBS02/BBSHD через Web Serial API.
Single-file HTML, vanilla JS, без сборщиков и фреймворков.

## Железо заказчика
Trek Roscoe 8 (2020) + BBS02B 48V 750W, контроллер HZXT SZZ9, FW V2.0.1.1,
дисплей 850C, 32T перед / SRAM PG-1230 11-50T зад, колесо 27.5x2.8,
райдер 95 кг, батарея 48V ~20Ah, ODO 5198 км. Есть газ и PAS.

## АНТИ-ГАЛЛЮЦИНАЦИИ (критично)
Протокол Bafang — reverse-engineered. Выдуманные байты = сломанный мотор.
- Нет точной спецификации → пиши // TODO: REQUIRES_VERIFICATION и оставляй placeholder
- Каждое утверждение о протоколе — со ссылкой на источник
- Не обещай 90 км/ч с 32T. Честная физика всегда

## ЧЕГО НЕТ В ЖЕЛЕЗЕ — НЕ РИСОВАТЬ НИКОГДА
- Температура мотора: датчика в BBS02 НЕТ
- Каденс как телеметрия: контроллер меряет, но наружу не отдаёт.
  Каденс только РАСЧЁТНЫЙ в симуляторе
- Дорожная live-телеметрия 10 Гц: разъём один (либо ноут, либо дисплей),
  и протокол дисплея != протокол конфигурации. Только «стендовый режим»

## ВНЕ СКОУПА v3.0
AI Tuning на «данных сообщества» (датасета не существует), WebXR/AR,
Telemetry Cloud Sync

## Технические ограничения
- НИКАКОГО localStorage — только IndexedDB
- Web Serial работает только по HTTPS или file://
- Только desktop Chrome/Edge/Opera
- Тема: светлая rally по умолчанию + тёмная по переключателю,
  обе на ОДНОМ наборе CSS-переменных

## Верные спеки (в мастер-гайде были ошибки)
- Max RPM: BBS01 ~78-100, BBS02 ~120, BBSHD 130-150 (НЕ «130 для всех»)
- Ток: BBS01 18A, BBS02 25A, BBSHD 30A
- Коды ошибок: 02 = газ, 08 = контроллер/мотор, 21 = ДАТЧИК СКОРОСТИ
  (не overcurrent), 30 = связь, 10 = перегрев
- Предел скорости 32T/11T/27.5x2.8: 44-48 км/ч

## Безопасность записи
- Авто-бэкап .el ДО любой записи
- Write All заблокирован, если бэкапа нет
- Preview дельты + confirm перед записью
- .el должен быть байт-в-байт совместим с Penov tool

UI и тултипы — русский. Код и комментарии — английский.
```

## 1. Разложить файлы и залить на сервер

```
Найди на диске файлы bbs-flash.html, bafang_intelligence.md, ROADMAP.md
(проверь Downloads и Documents). Собери их в Documents\BBS_Flash_v3\.
Если bbs-flash.html есть в нескольких копиях — оставь самый большой,
это актуальная версия (~78 КБ, с симулятором).

Потом залей все три на сервер root@5.181.23.24 в /var/www/html/
Пароль спроси у меня в момент подключения, в файлы не записывай.
```

## 2. Настроить nginx на сервере

```
Подключись по SSH к root@5.181.23.24 и сделай:
1. В /etc/nginx/sites-available/roomscope замени "listen 80 default_server;"
   на "listen 9090;"
2. Создай /etc/nginx/sites-available/bbsflash: listen 80 default_server,
   root /var/www/html, index index.html, try_files $uri $uri/ =404
3. Включи симлинком в sites-enabled
4. В /var/www/html: index.nginx-debian.html в .bak, симлинк index.html
   на bbs-flash.html
5. nginx -t — если ошибка, покажи мне и НЕ перезагружай
6. Если ок — systemctl reload nginx
7. Проверь curl -I http://localhost/ и http://localhost:9090/

Room Scope — статика, proxy_pass нет, uvicorn на 127.0.0.1:8000 не трогай.
```

## 4. Спринт S2 — Reality Check

```
Спринт S2 по ROADMAP.md. Реализуй модуль RealityCheck по разделу 4
файла bafang_intelligence.md.

Три уровня:
1. Жёсткий предел по передаче: v = max_rpm * (звезда/малая_звезда)
   * длина_окружности * 60 / 1000. Для 32T/11T/27.5x2.8 должно выйти 44-48 км/ч
2. Мягкий предел по мощности — предупреждение, не блокировка
3. Тепловая эвристика: ток >= 22A И расчётный каденс < 60 об/мин -> красное
   предупреждение

Правило: предупреждать, но НЕ запрещать. Блокировать только реальные
аппаратные пределы (ток выше потолка контроллера).

Crr и CdA сделай переключаемыми пресетами покрытия (асфальт 0.004 /
гравий 0.008 / грунт 0.012 / грязь 0.018), НЕ константами.
```

## 5. Спринт S3 — приборка

```
Спринт S3. Сделай rally-приборку по разделу 5 bafang_intelligence.md.

SVG, не canvas. Светлая тема по умолчанию, палитра в разделе 5.1.

Приборы:
- Спидометр стрелочный, красная зона начинается на v_gear_limit
  (динамическая, из передач!)
- Шкала тока: зелёная <=18A, жёлтая 18-22, красная >22
- Тахометр каденса с «холодной зоной» 70-100 об/мин зелёным
  и <60 красным — это главный обучающий элемент
- Анимация байка: наклон = уклон, колёса = скорость, педали = каденс
  и меняют цвет при выходе из зоны 70-100

Обязательно prefers-reduced-motion.
```

## 6. Спринт S4 — тултипы и локализация

```
Спринт S4. Возьми таблицу из раздела 6 bafang_intelligence.md
(Russian Localization) и сделай тултипы ко ВСЕМ параметрам.

Формат каждого: что делает (1 строка) / при увеличении -> / при уменьшении ->
/ предупреждение о риске (только где риск реален).

Плюс ComparativeBars: A/B дельты. КРИТИЧНО — для «пикового тока» и
«тепловой нагрузки» рост = КРАСНЫЙ, не зелёный. Иначе интерфейс будет
подталкивать к перегреву.
```

## Полезные команды в самом Claude Code

| Команда | Что делает |
|---|---|
| `/init` | Сгенерировать CLAUDE.md автоматически по проекту |
| `/clear` | Очистить контекст между задачами (экономит токены) |
| `/model` | Переключить модель (Opus для исследования, Sonnet для кода) |
| `Esc` | Прервать, если ответ пошёл не туда |
| `claude --continue` | Продолжить прошлую сессию |
