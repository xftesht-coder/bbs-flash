# Промт: одностраничный лендинг для BBS Flash

Создать одностраничный лендинг для веб-конфигуратора моторов **BBS Flash** — инструмента настройки кареточных мотор-колёс Bafang (BBS01 / BBS02 / BBSHD) через браузер по протоколу Web Serial.

## Целевая аудитория
DIY-сборщики и владельцы электровелосипедов в городах РФ, которые хотят самостоятельно настроить контроллер мотора (ток, помощь педалей, газ, калибровку колеса) без платных Windows-программ и кабелей. Едут и по асфальту, и по лесу. Ценят безопасность железа и честную физику.

## Структура разделов

1. **Первый экран.** Название BBS Flash, оффер: «Настрой свой мотор Bafang через браузер за 5 минут — без софта и кабелей». Кнопка «Открыть конфигуратор». Крупное фото электровелосипеда с кареточным мотором.
2. **Возможности.** Чтение/запись параметров контроллера, Safety Gate (авто-бэкап перед записью), Reality Check (честный предел скорости/мощности), симулятор поездки.
3. **Как это работает.** 5 шагов: кабель UART в мотор → открыть в Chrome/Edge → подключиться → считать всё → подкрутить и записать.
4. **Поддерживаемые моторы.** Сетка из 3–6 карточек: BBS01 (18A), BBS02 (25A), BBSHD (30A) — с коротким описанием и пределом тока.
5. **Почему безопасно.** Авто-бэкап `.el` до любой записи, проверка контрольных сумм, честная физика, «окирпичить контроллер невозможно» (валидация до записи).
6. **Калькулятор.** Звезда спереди + звезда сзади + диаметр колеса → примерная максимальная скорость (честная формула, без обещаний 90 км/ч).
7. **Отзывы.** 3 карточки: имя, город, текст (реальный тон DIY-райдера).
8. **FAQ.** 5 вопросов: работает ли в телефоне (нет, только desktop Chrome/Edge/Opera), безопасна ли запись, совместимость с дисплеем 850C, можно ли убить мотор, где взять кабель UART.
9. **Форма заявки.** Имя, Telegram или email, модель мотора, чекбокс согласия на обработку.

## Требования к дизайну и вёрстке

- **Стиль:** хайтек + велосипедно-гоночная (rally) эстетика. Тёмные панели, неоновые акценты, техничный вид — не «уютный лендинг услуги», а «инструмент тюнинга».
- **Палитра:** фон тёмных панелей `#0b1020`/`#0e1730`; акценты неон cyan `#22d3ee` и green `#34d399`; предупреждение amber `#fbbf24`; опасность red `#f87171`. Линии-рейлы `rgba(34,211,238,.35)`.
- **Темы:** светлая «rally» по умолчанию + тёмная (переключатель), обе реализованы на **одном наборе CSS-переменных** (без дублирования стилей).
- **Типографика:** крупная, техническая. Цифры, коды ошибок (02/08/21/30/10) и параметры — моноширинным шрифтом.
- **Анимации:** плавные, с уважением к `prefers-reduced-motion`. Без тяжёлых библиотек.
- **Адаптив:** мобайл + десктоп, но основной сценарий — десктоп (Web Serial доступен только в desktop Chrome/Edge/Opera по HTTPS).
- **Контент:** честная физика, реальные спеки Bafang (ток BBS01 18A / BBS02 25A / BBSHD 30A; предел 32T/11T/27.5×2.8 ≈ 44–48 км/ч). Никакой ложной рекламы «90 км/ч».
- **Контакты в подвале:** Telegram-бот/канал, ссылка на GitHub (исходники), почта. INN/реквизиты — если есть юрлицо.
- **Плейсхолдеры:** все поля формы и калькулятора на русском, с понятными подсказками.
- **Техника:** одностраничный статический HTML/CSS/JS, без сборщиков и фреймворков (vanilla). Кнопка «Открыть конфигуратор» ведёт на `https://bbsflash.neochoice.ru`.
