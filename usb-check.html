Проверка USB-кабеля

Первый шаг для Android + OTG. Эта страница определяет USB-кабель; она не настраивает мотор.

  1. Открой эту страницу в Chrome на телефоне.
  2. Подключи USB-кабель программирования к телефону через OTG. Мотор подключать не нужно.
  3. Нажми кнопку ниже, выбери свой кабель и разреши браузеру доступ.

Данные для подключения

VID/PID помогут выбрать драйвер. Обнаружение кабеля ещё не подтверждает возможность чтения и записи мотора.

Кабеля нет в списке?

Проверь OTG в настройках телефона, адаптер с передачей данных и разъёмы. Закрой приложения, которые используют USB. Если список пуст, сообщи об этом вместе с моделью телефона и версией браузера.

Страница не открывает UART, не отправляет команды кабелю и не загружает данные на сервер. Серийный номер USB не собирается. Наличие WebUSB — не подтверждение поддержки конкретного кабеля.
