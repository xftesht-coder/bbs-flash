# Safety / Ограничения 3.1.0

**This release has no physical motor validation.** Software tests use synthetic serial streams. Never treat them as proof that a particular controller, battery or drivetrain is safe.

## Допуск записи

По умолчанию запись выключена. Известной считается только сигнатура manufacturer `HZXT`, model `SZZ9`, FW `2.0.1.1`, nominal code `2` (48 V), max current от 1 до 25 A. Это распознавание исторически указанного оборудования владельца проекта, **не аппаратная сертификация**. HW отображается и сохраняется, но ещё не используется для расширения матрицы допуска. Другие сигнатуры — read-only. На протоколе нет проверенного уникального серийного номера: похожая сигнатура не доказывает, что это тот же физический контроллер.

Для записи нужны: успешный General, полное чтение в текущем сеансе, доступное IndexedDB, отдельное включение experimental mode, валидный профиль, два совпавших чтения, сохранённая и проверенная копия, явное подтверждение точной дельты. После подтверждения исходные данные читаются снова; изменения отменяют запись. Для каждого записанного блока проверяется readback, затем читаются все три блока.

## Пределы

- Общий ток не может превышать меньший из General.maxCurrent и потолка распознанной модели. 18/25/30 A в симуляторе — границы принятой модели, не универсальная маркировка всех вариантов Bafang.
- Cutoff проверяется по классу напряжения General. Правильное значение всё равно зависит от батареи/BMS: приложение не измеряет химический состав, число ячеек или состояние батареи.
- `.el` и wire-поля проверяются целиком: целые числа, допустимые перечисления, массивы длиной 10, SV < EV, ограниченный размер файла, обязательные ключи. Неверные значения не заменяются нулями и не обрезаются до байта.
- Новое значение PAS Time of Stop ниже 20 × 10 мс не записывается. Увеличение PAS/throttle start current выше 20% запрещено. Исходные значения могут читаться и экспортироваться без такого изменения. Это консервативная политика приложения, не заявленный предел любого firmware.
- Пресеты не меняют батарею, колесо, датчик скорости, ручку газа, designated assist и speed limit. Общий ток может только снизиться; Time of Stop не снижается. Исторические образцы не являются рекомендациями.

## Обрывы, копии и восстановление

UART не имеет transaction ID и не даёт атомарной записи нескольких блоков. Запись могла состояться даже без ACK. Нет автоматического retry или rollback. После сомнительного результата приложение закрывает сеанс; подключись заново и считай все блоки. Сверь их с сохранённой копией, прежде чем решать, что восстанавливать.

IndexedDB может быть очищен пользователем/браузером. Скачай `.el` и raw JSON отдельно. «Загрузить копию в черновик» не записывает контроллер. Обычная процедура записи сохраняет ещё одну копию текущего состояния перед восстановлением. Копия черновика, браузерный download без подтверждённого сохранения или копия другого сеанса не заменяют свежий backup-before-write.

Перед действиями на реальном оборудовании нужен подходящий кабель с проверенной распиновкой, закреплённый велосипед, свободное ведущее колесо и доступ к отключению питания. Приложение меняет настройки и не является средством обновления firmware. Защита контроллера от неверных чисел не гарантируется.

## Расчёты

Reality Check — эвристика сочетания тока PAS ≥22 A и расчётного каденса <60 rpm. Отсутствие предупреждения **не означает**, что нагрева нет. Температура не измеряется и не прогнозируется. Дальность основана на стационарной механической модели, фиксированном КПД и 15% резерве энергии. Ветер, ускорения, помощь ногами, температура и деградация батареи не учтены. Настройки Crr, CdA, передаточного отношения, напряжения и RPM — пользовательские допущения.
