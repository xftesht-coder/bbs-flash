# BBS Flash 3.4.1 — подключение SZZ9 по реальному журналу

Исправлен отказ подключения «Контрольная сумма не совпала» для присланного владельцем ответа HZXT SZZ9 / HW 1.1 / FW 2.0.1.1 / 48 V / 25 A. Последний байт этого 19-байтового General — 0x22, тогда как обычная аддитивная сумма даёт 0x30.

Добавлено точное распознавание всех 19 байтов этого известного ответа и обязательное второе идентичное чтение до установления соединения. Это поддержка конкретного захваченного пакета, а не выведенное правило контрольной суммы для других контроллеров. Интерфейс и журнал показывают режим совместимости. Старый обработчик игнорировал хвост General; полное отключение проверки не возвращается.

Сохранены строгие проверки Basic/PAS/Throttle, аппаратные лимиты, экспериментальное включение записи, резервная копия, подтверждение изменений и проверка результата записи. Реальных захватов блоков настроек и подтверждённой записи пока нет.

Проверки: точный пакет владельца, все границы разбиения потока, одиночные изменения каждого бита пакета, обрыв/ошибка/изменение второго ответа, подключение и чтение через имитацию порта в браузере, прежние тесты записи и профилей.
