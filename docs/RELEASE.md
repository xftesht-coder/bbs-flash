# BBS Flash 3.4.3 — выпуск для BBS02 владельца

Допуск записи ограничен точной конфигурацией: HZXT SZZ9 / HW 1.1 / FW 2.0.1.1 / 48 В / заявленный контроллером максимум 25 А. Другая ревизия или другой предел тока остаются доступны только для чтения. Профили не повышают исходный общий ток автоматически.

Аудит выявил потерю черновика при повторном чтении, отсутствие копии перед редактированием и допуск записи, частично зависящий от UI. Новые функции не добавлены; дублирующий landing заменён перенаправлением на единственную главную страницу.

Цикл CONNECT → READ → BACKUP → EDIT → VALIDATE → WRITE → READ-BACK → VERIFY закреплён в ядре. Два чтения и проверенная копия предшествуют загрузке в редактор. Перед записью контроллер сравнивается с исходным чтением; изменение данных отменяет операцию. Неопределённый результат записи закрывает соединение. Повторное чтение предупреждает о замене правок, а запись одного блока сохраняет остальные правки черновика.

Проверки: 41 Node-тест, 25 сценариев Edge, проверка синтаксиса и npm audit (0 известных уязвимостей). Включён повтор всех четырёх реальных ответов владельца, но запись в автоматических тестах имитируется.

30 сентября 2026 владелец подтвердил успешную запись с сообщением о повторном чтении всех блоков и последующий заезд с «Полным вперёд» на ранее опубликованной 3.4.2. Это сообщение владельца, а не независимое испытание каждого профиля. Изменения 3.4.3 проверены программно. Физическое восстановление, независимое чтение Penoff и сырые кадры записи/ACK ещё не подтверждены; подробности — в docs/BENCH-VALIDATION.md.
