# BBS Flash 3.4.2 — checksum всех блоков UART

Исправлена ошибка чтения Basic: контроллер присылал 0x62, приложение ожидало 0x78. Причина — применение правила исходящей записи к входящим ответам legacy UART. Правило RX block + 2 + payload (mod 256) согласуется с реальными General/Basic владельца и независимыми опубликованными пакетами всех четырёх блоков.

Точечное исключение 3.4.1 заменено определением формата по General, двумя одинаковыми чтениями для legacy и фиксацией формата на весь сеанс. Повреждённый ответ нельзя принять переключением на другой checksum. Исходящие команды записи и подтверждения ACK не изменены. Сохранены резервная копия, подтверждение изменений, аппаратные лимиты и проверка результата записи.

Проверены исходные пакеты, все границы разбиения потока, повреждение каждого бита в независимых примерах, запрет смены формата, backup/write/readback на имитаторе и отображение считанного лимита 24 А в браузере. Физическое полное чтение, запись и восстановление ещё требуют проверки владельцем.
