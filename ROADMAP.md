# Roadmap после 3.2.0

Релиз 3.1.0 закрывает найденные программные дефекты и делает публикацию воспроизводимой. Он **не закрывает аппаратный Definition of Done v3.0**. Старый план сохранён в [архиве](docs/archive/ROADMAP-v3.0.md); невыполненные пункты ниже не отмечены как готовые.

## 3.1.0: что входит

- [x] Единый путь записи для Basic / PAS / Throttle / Write All с ограничениями, проверенной копией, дельтой и readback.
- [x] Неизвестная сигнатура не получает автоматически лимиты BBS02; запись запрещена.
- [x] Ошибочные кадры, timeout, disconnect, отказ IndexedDB и неверные `.el` прекращают операцию.
- [x] `.el` проверен на fixture исходного инструмента Penoff; преобразования индексов и граничные значения покрыты тестами.
- [x] Общая модель расчётов: при 32/11, окружности 2.194 м и заданных 120 об/мин геометрический предел ≈46.0 км/ч. **120 об/мин — вводимое допущение**, не измеренный RPM SZZ9.
- [x] Эвристика нагрузки использует ток выбранного PAS, а не общий потолок. Температура не моделируется.
- [x] RU/EN, две темы, mobile navigation, работа без Web Serial и при отказе IndexedDB.
- [x] Автоматические тесты с имитацией порта; корректная главная страница и HTTPS deployment.
- [ ] Чтение/запись каждого блока на физическом SZZ9 с независимой проверкой в Penoff.

## 3.2.0: Race Garage

- [x] Компактный гараж, приборка расчётного заезда, PAS-переключатель и светлая/тёмная темы.
- [x] Справочник полей RU/EN по материалам Penoff: смысл, эффект изменения и границы знаний; видимое авторство Bafang и Penoff.
- [x] Добровольная анимация: по умолчанию остановлена, пауза на скрытой вкладке и reduced motion. Только визуализация расчётов, без команд мотору.
- [x] Проверки приборки, справочника, мобильной раскладки и прежних сценариев записи.

## P0 · Следующий допуск: проверка на стенде

До расширения записи и любых заявлений о совместимости:

1. **Снять эталон обмена.** Записать маркировку контроллера, HW/FW, напряжение, лимит General, USB-UART и версии браузера. Сохранить сырые General/Basic/PAS/Throttle кадры и `.el` из независимого инструмента. Удалить персональные данные перед публикацией.
2. **Проверить протокол.** Сопоставить длины, порядок байтов, checksum и 2-/3-байтовый ACK на реальном оборудовании. Не ослаблять проверку неизвестных вариантов без отдельного fixture и исследования.
3. **Проверить восстановление.** На закреплённом велосипеде, со свободным ведущим колесом и возможностью отключить питание выполнить контролируемое малое изменение каждого блока, readback, возврат исходного профиля и сравнение независимым инструментом. Проверить отказ при отключении кабеля; не испытывать разрыв питания в момент записи на единственном рабочем контроллере.
4. **V1 — каденс.** Измерить реальный предел с независимым датчиком, указать передачу, окружность, напряжение и метод. Сам факт чтения General не даёт max RPM.
5. **V2 — Time of Stop.** Исследовать принятие и поведение допустимых значений в контролируемых условиях. Не переносить неподтверждённый совет «10 безопаснее» на все прошивки; политика 3.1.0 остаётся консервативной.

Готово, когда опубликованы журнал, fixture, аппаратная матрица, подтверждённый restore и результаты V1/V2. Только тогда отдельный PR меняет статус конкретной сигнатуры. Запись для неизвестных моделей остаётся запрещённой.

## P1 · 3.3: точность и удобство

- **Матрица совместимости BBS01/BBS02/BBSHD.** Добавлять только проверенные сочетания manufacturer/model/HW/FW/voltage/current. Критерий: аппаратные данные и регрессионные кадры для каждого допуска; нельзя использовать выбор модели симулятора как разрешение записи.
- **Уточнение справочника по прошивкам.** Базовые объяснения Penoff добавлены в 3.2.0; подтвердить направление Slow-start, Work Mode и задержки на конкретном железе, связать карточки с аппаратными доказательствами.
- **Калибровка модели.** Сравнить измеренные напряжение, скорость, дистанцию и расход минимум на ровном участке и подъёме; оценить ошибку и показать диапазон, а не единственное «точное» число. Добавить помощь райдера, ветер и переменный КПД только с проверяемыми параметрами.
- **История копий.** Выбор по времени/сеансу, сравнение перед восстановлением, проверка доступного хранилища и экспорт архива. Критерий: полное восстановление без потери исходных данных; миграция IndexedDB протестирована.
- **Расширенная доступность.** Keyboard/screen-reader проверка, удобная навигация по дельте, контроль контраста. Критерий: все сценарии выполняются без мыши на обеих локалях.

## P2 · После 3.3

- Устанавливаемая PWA: сначала стратегия обновления, которая никогда не меняет код во время записи. Проверки offline/обновления/устаревшего кэша обязательны. До этого service worker намеренно отсутствует.
- Сравнительные графики A/B с диапазоном ошибки измерений. Приборка 3.2.0 показывает только точечную оценку; добавить диапазон после калибровки, сохранив reduced motion и паузу на скрытой вкладке.
- Фильтры журнала, экспорт воспроизводимого отчёта о проблеме, сочетания клавиш.
- Отдельное исследование display protocol / внешних датчиков. Не выдавать конфигурационный UART за дорожную телеметрию и не рисовать несуществующую температуру.

## Правила будущего релиза

Сначала тесты и PR, затем merge, проверка опубликованного сайта по хешам и smoke-сценариям, затем release tag. У нового аппаратного допуска есть собственные доказательства. AI tuning, автоматическая настройка тока по непроверенным профилям, CAN и прошивка firmware не входят в ближайший план. Даты аппаратных этапов не обещаются до появления стенда.
