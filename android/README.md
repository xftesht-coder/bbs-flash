# BBS Flash · Android OTG

Android 0.3.0-rc1, интерфейс и профили веб-версии 3.5.0. Кандидат для повторной проверки USB на телефоне владельца, не подтверждённый аппаратный релиз. Android 8+ и USB Host/OTG. Интернет для настройки не нужен; передача диагностики отключена в сборке. Учётная запись и покупки не подключены. Совместимость записи остаётся ограниченной проверенной версией контроллера владельца — приложение не расширяет список поддерживаемых моторов.

## На iQOO

1. Установить APK. Android может запросить разрешение установки для браузера/проводника.
2. Подключить USB-C OTG → USB-кабель программирования Bafang UART → мотор. При необходимости включить OTG в настройках телефона.
3. Открыть приложение → «Подключить» → выбрать кабель → разрешить доступ USB.
4. «Считать все блоки». Дождаться проверенной резервной копии, скачать её отдельно через проводник. После проводника заново подключиться и считать мотор: уход в другое приложение закрывает USB-сеанс.
5. Выбрать профиль, посмотреть изменения, разрешить запись для текущего подключения. «Проверить и записать всё» → подтвердить изменения. Дождаться сообщения о подтверждении повторным чтением.
6. Отключиться, выключить питание мотора и отсоединить кабель программирования перед поездкой.

Выбор профиля и чтение не записывают настройки. При обрыве связи часть блоков могла записаться: автоматического повтора или отката нет. Снова подключиться и прочитать фактические настройки.

Драйверы: usb-serial-for-android 3.11.0 (FTDI, CP210x, CH34x, PL2303, CDC и др.). По истории владельца установлен адаптер Ch34xSerialDriver, USB 1a86:7523, Android API 36. Версия 0.2.0-preview получала TIMEOUT и одиночный байт 10 вместо полного ответа. В 0.3.0-rc1 изменено нативное чтение USB; результат на этом физическом кабеле ещё требуется проверить. Если адаптер не найден, проверить OTG/переходник: это отдельная ошибка обнаружения USB.

Хранилище приложения отделено от браузера. Старые .el импортируются через системный проводник. Удаление приложения удалит его локальные данные; отдельно сохранённые файлы останутся. Для обновлений нужен тот же ключ подписи и больший versionCode.

## Сборка

JDK 17+, Android SDK 36/build-tools 35.0.0, Gradle 8.11.1, Node 24.19+. Указать ANDROID_HOME и JAVA_HOME. Из каталога репозитория:

```sh
bash android/gradlew -p android assembleDebug testDebugUnitTest lintDebug
node --test android/tests/bridge.test.cjs tests/android-capture.test.cjs
```

`bundleSite` копирует локальные HTML/JS/CSS/шрифты и добавляет транспортный мост перед приложением. UART-протокол, валидация, резервные копии и read-back остаются в `src/core.js` / `src/storage.js`. При изменении сайта APK нужно пересобрать; сетевых обновлений кода нет.

Проверка моста на браузерном имитаторе мотора:

```sh
BBS_TEST_ANDROID=1 BBS_BROWSER_FILTER='mock serial: all 3' node tests/browser.cjs
BBS_TEST_ANDROID=1 BBS_BROWSER_FILTER='hill profile warns' node tests/browser.cjs
```

Нативный мост доступен только главному фрейму локального HTTPS-origin WebViewAssetLoader. Внешние страницы не загружаются в WebView. USB выбирает пользователь; запись завершается только после возврата USB-драйвера. При фоне/отключении инвалидируется сеанс; старые ответы не принимаются новым сеансом. APK preview не является подтверждением испытаний на реальном iQOO/кабеле.

Результаты новой проверки и ограничения: [USB-RC1-RELEASE.md](USB-RC1-RELEASE.md). История подключений: [HISTORY-RELEASE.md](HISTORY-RELEASE.md). Эмулятор и программный имитатор мотора не подтверждают аппаратную совместимость. Google Play ещё не опубликован.
