# CHANGELOG

## v2.1 — Safety Gate + Reality Check (7 августа 2026)

Спринт S1.5 + S2 из `ROADMAP.md`. Закрыты все 4 блокера из чеклиста §5,
которые нашёл автоаудит. UI остаётся английским — локализация в S4.

**Проверка:** `pwsh tools/Audit-BbsFlash.ps1` → 0 BLOCKER;
`node tools/smoke.mjs bbs-flash.html` → 18/18.

### Безопасность записи

- **Гейт на все кнопки Write, не только на «Write all».** Раньше `basWrite` /
  `pasWrite` / `thrWrite` уходили на провод без подтверждения и без проверки
  бэкапа — ровно та дыра, ради которой гейт и делался. Теперь все три идут
  через `guardedWriteBlock` → `safetyGate`.
- **Preview дельты.** `computeDelta` показывает построчно, какие значения
  меняются относительно последнего чтения, включая отдельные ячейки таблицы
  ассистов. Confirm без списка изменений больше не бывает.
- **AutoDetect.** `detectFamily` выводит семейство мотора из потолка тока в
  GEN-блоке и жёстко ограничивает его документированным пределом
  (BBS01 18A / BBS02 25A / BBSHD 30A). Запись с `LC` выше потолка блокируется
  до отправки кадра. Семейство помечено в UI как *inferred* — контроллер его
  не сообщает.
- **Watchdog на ACK.** Каждый запрос теперь с дедлайном 2500 мс. Выдернутый
  кабель или обесточенный мотор посреди записи даёт явную ошибку и совет
  перечитать блок, а не бесконечное ожидание.

### Протокол

- **Проверка контрольной суммы входящих кадров.** В коде стояло
  `// checksum ignored` — битый кадр молча становился настройками.
  `verifyRxChecksum` считает обе правдоподобные версии спана и логирует, какая
  сошлась. Строгий режим (чекбокс во вкладке Wire Log) отбрасывает
  несходящиеся кадры.

  используется; после этого строгий режим можно включить навсегда.

### Reality Check (спринт S2)

- **Предел по трансмиссии вместо константы.** `REF_MAX_KMH = 45` удалён.
  `gearLimitKmh` считает `maxRpm × (звезда / малая звезда) × длина окружности`.
  Эталон 32T/11T/27.5×2.8 при 120 об/мин → **47.8 км/ч**, в вилке 44–48.
- **Честный диаметр колеса.** Раньше `дюймы × 0.0254` игнорировало покрышку.
  Теперь ETRTO обода + 2 × ширина покрышки: 27.5×2.8 → 2282 мм окружности.
- **Тепловая эвристика.** Ток ≥22A И расчётный каденс <60 об/мин → предупреждение
  плюс рекомендация, на какую звезду переключиться, чтобы выйти за 60. Каденс
  считается в той звезде, в которой райдер реально едет в гору (поле ввода) —
  перегрев BBS02 это выбор передачи, а не число ватт.
- **Crr и CdA — пресеты, не константы.** Асфальт 0.004 / гравий 0.008 /
  лесная тропа 0.012 / грязь 0.018; посадка 0.45 / 0.55 / 0.68.
- **Потолок тока из железа.** `CONTROLLER_MAX_A = 25` удалён; симулятор и шкала
  амперметра берут значение подключённого контроллера. Шкала спидометра тоже
  масштабируется под реальный предел передачи, а не под фиксированные 50 км/ч.

### UI

- **Инверсия цвета в дельтах.** Рост тока, Keep Current и числа «горячих»
  уровней PAS красятся красным с меткой MORE HEAT. Раньше рост любого числа
  выглядел одинаково — интерфейс подталкивал к перегреву.
- **`prefers-reduced-motion`.** Анимация гонки и переходы отключаются; байки
  ставятся в статичные позиции пропорционально скоростям.
- **Ноль Web Storage.** `sessionStorage` для дисклеймера убран (правило проекта
  — только IndexedDB), гейт живёт в памяти.
